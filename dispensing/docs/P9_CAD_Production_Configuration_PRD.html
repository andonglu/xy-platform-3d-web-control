P9：CAD 生产仿真与人工配置需求

把 CAD 模型、工件位姿、夹具、点胶区域、上料参数和生产过程纳入同一个可配置、可保存、可仿真的作业。人工负责工艺与设备事实，系统负责坐标计算、路径生成、校验和状态执行。

1. 背景与目标

当前系统已支持上位机解析 STL/DXF、生成带法向路径、三轴/五轴模拟执行和 Web 路径预览，但原始 CAD 没有同步到服务端，工件坐标、夹具、上料和连续生产也尚未形成完整配置流程。

核心产品决策：需要人工确定的工艺和设备信息，必须提供明确窗口接收并保存；系统不得仅凭 STL 猜测抓取位置、夹紧方式或应涂胶区域。

当前问题

  • 上位机上传路径而非原始模型，Web 无法恢复同一工件场景。
  • 模型平移旋转已有，但没有正式工件坐标系和夹具配置。
  • 几何轮廓可生成路径，但“哪里需要点胶”缺少人工标注入口。
  • 只有单件加工执行，没有上料、装夹、下料和批次循环。

目标结果

  • 人工可在一个工程中完成全部必要设置。
  • 上位机、服务和 Web 对模型及机器坐标保持一致理解。
  • 配置错误在仿真前被阻止并定位到具体字段或路径。
  • 无需真实硬件即可连续模拟多件生产过程和异常恢复。

2. 范围与角色

2.1 P0：本阶段必须完成的最小闭环

  1. 导入原始 CAD 并同步到服务端和 Web。
  2. 人工设置夹具、工件位置与朝向，预览机器坐标。
  3. 人工选择点胶面、边、轮廓或 DXF 实体并配置工艺。
  4. 人工设置虚拟抓取、放置、夹紧、下料和传感器参数。
  5. 执行单件及连续生产仿真，支持暂停、停止、复位和失败重试。
  6. 保存并重新加载完整工程。

2.2 P1：后续增强，不作为 P0 完成条件

  • 探针、三点找正和视觉自动定位。
  • 自动识别密封面、粘接面等工艺语义。
  • 复杂曲面自动填充和测地等距路径。
  • 真实 PLC、机器人、输送线和质量检测设备接入。

2.3 角色与职责

角色主要职责本阶段操作边界
工艺工程师确定模型、坐标、夹具、点胶区域、工艺和上料参数。在上位机创建、编辑、校验和保存工程。
操作员加载已配置工程，执行仿真和处理暂停/失败。可运行、单步、停止和复位；不修改工艺字段。
系统接收人工数据并自动计算、校验和同步。生成机器坐标、路径与五轴姿态；不替代人工做工艺判断。

本阶段不引入账号、审批或权限管理系统，上述角色用于定义操作职责。

编辑入口：人工工艺配置统一放在 DispenseStudio；Web 用于同步场景、仿真操作和结果查看，避免双端同时编辑造成数据与坐标不一致。

3. 核心对象与完整流程

模型 Model

原始 STL、显示名称、单位、文件标识和同步状态。DXF 作为轮廓来源，不冒充三维实体。

工件放置 Placement

模型在夹具中的平移、旋转和缩放，以及关联的夹具。

夹具 Fixture

夹具机器位姿、机械定位方式、夹紧动作和到位条件。

点胶区域 DispenseRegion

人工选中的面、边、轮廓、切片范围及其工艺参数。

上料配方 LoadingRecipe

抓取、搬运、放置、夹紧、松开和下料所需的人工设置。

生产作业 ProductionJob

上述对象的统一工程，以及仿真状态、批次计数和事件记录。

核心流程

导入 CAD→设置工件与夹具→标注点胶区域→配置上料→校验并保存→连续生产仿真

进入条件：工艺工程师新建工程或加载已有工程。完成条件：模型与配置同步成功，至少一件工件完成上料、装夹、点胶、下料，且全部状态与失败原因可查看。

FR-01

CAD 模型导入与场景同步

目的：让上位机、服务端和 Web 使用同一份原始模型、同一个模型 ID 和同一位姿，不再只传路径线。

窗口与触发

工程师在“模型”窗口选择 STL 或 DXF。STL 进入三维模型列表；DXF 进入轮廓来源列表。导入后显示模型、单位确认、同步状态和错误信息。

处理规则与结果

  • 导入成功后保留原始文件内容，解析失败不得生成空模型。
  • 模型同步成功前，工程保持“配置草稿”，不能进入完整生产仿真。
  • Web 按工程位姿显示模型；相机自动居中只能改变观察视角，不能修改机器坐标。
  • 替换已被引用的模型时，要求重新确认区域与路径；删除被引用模型时阻止并显示引用位置。
人工输入必填默认/选项校验与反馈
原始文件是STL / DXF无法读取、格式不支持或内容为空时显示具体失败原因。
显示名称是取文件名同一工程内名称不可重复。
源文件单位是mm；可选 cm、inch导入时确认，系统统一换算为 mm；未确认时禁止生成路径。
模型用途是工件 / 夹具 / 仅轮廓“仅轮廓”不要求生成三维实体。
重新导入否保留名称和 ID几何变化后使原路径标记为“需重新生成”。

异常恢复：同步中断时保留本地工程和已输入字段，状态显示“同步失败”，允许重试；不得把上次成功状态当作本次成功。

FR-02

工件坐标系、夹具与机械固定设置

目的：明确工件在机器中的实际位置和朝向，并把机械固定事实转化为仿真启动条件。

窗口与触发

“工件与夹具”窗口分为夹具库、工件放置、机械固定和坐标预览四区。工程师选择夹具后输入工件相对夹具的位姿；点击“应用”后更新场景和机器坐标。

坐标规则

T_M_C = T_M_F × T_F_C
工件点使用完整位姿变换；法向只使用旋转部分并重新单位化。每个变换只能应用一次。

旋转单位为 °，顺序固定为 Rx → Ry → Rz；位置单位为 mm。系统同时显示选中的 CAD 坐标和换算后的机器坐标。

夹具人工输入必填默认/选项校验与说明
夹具名称 / 编号是无工程内唯一；编号保存后作为引用。
机器原点 X/Y/Z是0 / 0 / 0 mm必须是有限数值，并做机器可达性检查。
夹具旋转 Rx/Ry/Rz是0 / 0 / 0°按统一旋转顺序解释。
机械定位方式是定位销、挡块、压板、真空、其他“其他”必须填写说明。
夹紧方式与动作顺序是可编辑有序列表至少包含夹紧和松开动作。
工件到位条件是虚拟信号 / 人工确认完整生产仿真必须满足后才能加工。
夹紧到位条件是虚拟信号 / 人工确认未满足时禁止点胶并显示阻断原因。
工件放置输入必填默认值校验与说明
关联模型与夹具是当前选择任一缺失时不能应用。
工件偏移 X/Y/Z是0 mm表示工件相对夹具的位置。
工件旋转 Rx/Ry/Rz是0°表示工件相对夹具的朝向。
统一缩放是1必须大于 0；改变后路径需重新生成。
法向全局反向否关闭仅用于修正模型绕序错误；应用前必须预览。

结果：应用成功后保存工件放置并更新 Web 场景；任何位置、朝向或缩放变化都会将相关路径标为“需重新生成”，避免继续执行旧坐标。

FR-03

人工点胶区域标注与路径生成

目的：由工程师明确“哪里需要点胶”，系统根据选中几何和工艺参数生成路径，不自动猜测工艺语义。

窗口与触发

“点胶区域”窗口提供三维选择、区域列表、工艺参数和路径预览。工程师选择面、边、连续轮廓、DXF 实体或切片范围，点击“添加区域”后设置工艺并生成路径。

人工输入必填默认/选项处理与校验
区域名称是区域 01…工程内唯一。
几何来源是面 / 边 / 轮廓 / DXF / Z 切片空选择不能生成；保存时保留几何引用。
路径模式是边界 / 等高轮廓面的内部填充属于 P1。
Z 起止与层间距切片时必填读取模型范围；层间距 1 mmZ 止不得小于 Z 起；层间距必须大于 0。
起点与方向是自动起点 / 正向可反向、选择最近起点；闭合轮廓保持闭合。
法向方向五轴必填保持 / 反向显示法向箭头；零法向阻止生成。
法向偏置是0 mm按法向偏移 TCP，预览偏移后位置。
等弧长间距是2 mm；0 表示原始点不得小于 0；大于 0 时保留首尾点。
平滑次数与强度是2 次 / 0.5次数为非负整数，强度范围 0~1。
最大姿态步长五轴必填30°范围 1~30°，超限阻止执行。
进给速度是60 mm/s必须大于 0，并满足设备能力。
开阀前延时是0 ms不得小于 0。
提前关胶 / 关胶保持是0 ms不得小于 0。
退枪高度是0 mm不得小于 0，并检查上方空间。

生成结果

  1. 按最终工件位姿转换几何。
  2. 按区域设置提取边界或切片轮廓并串接。
  3. 计算法向、偏置、等弧长布点和平滑。
  4. 生成带 points + normals 的加工段。
  5. 执行三轴可达性或五轴姿态/行程预检查。
  6. 在场景中显示路径、方向、起点和法向；保存到区域。

异常：空区域、无效法向、路径少于两个点、超行程或姿态突变均使区域变为“无效”；错误定位到区域和路径点，修改后允许只重新生成该区域。

FR-04

自动上料、装夹与下料人工配置

目的：将人工确定的自动化动作转换为可重复执行的虚拟生产步骤。

边界：P0 只模拟动作和 IO，不直接驱动真实机器人、气缸或输送线。模型文件本身不包含抓取和夹紧知识，以下字段必须人工设置。
人工输入必填默认/选项校验与用途
生产模式是仅加工 / 完整生产仅加工可跳过上下料，但仍需工件与夹具条件。
来料方式完整生产必填托盘 / 输送线 / 人工放入决定等待来料和到位行为。
抓取位姿完整生产必填XYZ + RxRyRz可从场景拾取或手动输入。
放置位置完整生产必填选择夹具中的工件放置不得与抓取位姿混用。
接近 / 抬升高度是30 / 50 mm不得小于 0。
抓取与释放动作是有序动作列表动作顺序可编辑，缺少释放时阻止连续循环。
工件到位信号是PART_PRESENT / 人工确认未到位时保持等待或进入失败，不自动跳过。
夹紧到位信号是CLAMP_OK / 人工确认未满足时禁止点胶。
允许放置误差是[TBD] mm / °用于判断仿真上料是否需要报警，不自动修正工艺坐标。
下料位置完整生产必填XYZ + RxRyRz完成后工件离开夹具并解除占用。
动作等待时间是各动作 0 ms不得小于 0，仅影响仿真节拍。
批次数量是1 件正整数；达到数量后正常停止。

单步操作：工程师可分别执行“模拟上料、夹紧、松开、下料”，每一步显示前置条件、执行结果和当前工件位置。前置条件不满足时保持原状态并说明原因。

FR-05

单件与连续生产仿真

目的：在真实硬件接入前验证完整生产顺序、阻断条件和异常恢复，而不只验证针尖轨迹。

启动前检查

  • 模型同步成功且工程没有未应用的位姿修改。
  • 工件、夹具、机械固定和坐标设置完整。
  • 至少一个有效点胶区域，所有待执行路径已重新生成并通过预检。
  • 完整生产模式下，上料、装夹、下料和批次配置完整。
状态进入条件允许操作离开条件
待上料启动检查通过，夹具空闲开始、单步、停止收到来料后进入上料中
上料中抓取与放置动作执行暂停、停止工件到位且放置成功
待加工工件到位、夹紧到位开始点胶、单步、下料点胶命令被接受
点胶中路径开始执行暂停、停止路径完成或发生错误
待下料加工完成下料、停止松夹并允许移出工件
下料中工件搬运离开夹具暂停、停止夹具空闲，完成数加一
已完成达到批次数量复位、查看记录复位后回到待上料
已暂停人工暂停继续、停止继续回到原状态
已阻止任一安全或配置条件失败查看原因、复位、重试原因解除并人工确认后恢复

记录：每件工件显示序号、开始/结束状态、所用工程、当前步骤、失败原因和完成数量。P0 的“加工完成”只表示轨迹和配置流程完成，不代表真实胶量或粘接质量合格。

停止与重试：停止后立即关闭虚拟胶阀并保持当前工件占用状态；操作员必须选择“从当前步骤重试”或“复位并重新上料”，系统不得静默跳过失败步骤。

FR-06

完整工程保存、加载与失效标记

目的：人工输入和系统生成结果必须作为同一工程恢复，避免重新设置或误用旧路径。

保存内容

  • 原始模型及模型引用、单位、显示名称。
  • 夹具、机械固定、工件放置和坐标参数。
  • 点胶区域、几何引用、工艺参数、生成路径和法向。
  • 上料、装夹、下料和批次设置。
  • 工程数据版本及必要的兼容默认值。

行为规则

  • 字段修改后显示“未保存”；保存成功显示时间和工程名称。
  • 模型、位姿或区域几何改变时，不自动删除旧路径，但必须将其标为“需重新生成”并阻止执行。
  • 加载时缺少源模型，允许重新关联文件；未重新关联前可查看配置，但不能启动完整生产仿真。
  • 旧版本工程缺少新增字段时使用明确默认值并提示用户检查，不能静默把关键安全参数设为零。
  • 加载失败不覆盖当前已打开工程。

5. 共享规则与异常边界

唯一坐标事实：执行使用机器坐标；工件坐标和夹具坐标用于人工理解与配置。视图缩放、旋转和平移不改变任何加工数据。
人工输入优先级：抓取、放置、固定、点胶区域和工艺参数以人工保存值为准；自动计算结果必须可预览、可重新生成。
单位统一：内部位置和路径以 mm、角度以 °、时间以 ms、进给以 mm/s 表示；窗口必须显示单位。
同步不是执行许可：模型同步成功只代表场景一致；坐标、路径、行程、装夹等检查仍须分别通过。
错误不静默降级：模型缺失、法向无效、超行程、夹紧失败、上料失败均显示阻断原因，不得继续假装生产。
仿真与真实设备隔离：所有仿真窗口持续显示“模拟运行”，不得把虚拟 IO 成功解释为真实传感器成功。
数据修改后的失效：影响几何或坐标的修改使路径失效；影响上料顺序的修改使生产配置重新校验。
