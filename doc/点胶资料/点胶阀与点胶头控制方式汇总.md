# 点胶阀、点胶头与控制方式汇总

> 整理日期：2026-11-13。资料来源详见同目录 [资料来源.md](资料来源.md)，原始 PDF 见 `原始资料/` 子目录。
> 本文基于武藏（MUSASHI）、诺信 EFD（Nordson）、Techcon、睿斯合、铭赛等厂商公开文档及行业资料整理，供本项目虚拟点胶控制器建模与真实设备接入参考。

---

## 一、点胶系统的构成

```
上位机/运动控制器 ──→ 点胶控制器（胶阀控制器）──→ 胶阀（点胶头）──→ 针头/喷嘴
                           │
                        气源/电源/温控
```

- **运动平台**：三轴/四轴点胶机、在线式点胶机（本项目属于此类）
- **点胶控制器**：按阀类型分为针筒控制器、气动阀控制器、螺杆阀控制器、喷射阀控制器
- **胶阀（点胶头）**：精密点胶的执行部件
- **耗材**：针头、喷嘴、针筒、供料桶

## 二、主流点胶阀类型与工作原理

### 按驱动方式分类

| 类型 | 驱动 | 原理 | 特点 | 适用 |
|---|---|---|---|---|
| **时间-压力式（针筒）** | 压缩空气 | 气压按设定时间推针筒活塞出胶 | 结构最简单、成本最低；胶量受粘度/温度影响大 | 中低粘度 UV 胶、三防漆、精度要求低的预固定 |
| **气动撞针阀/顶针阀** | 气缸 | 弹簧压下撞针关胶，开阀气压推动撞针抬起，胶在供料压力下流出 | 断胶干净、不受气泡影响、低维护 | 中高粘度胶、通用点胶 |
| **回吸阀** | 气缸+真空 | 关胶时撞针向上运动并瞬间回吸断胶 | 无漏滴、无拉丝 | 易拉丝胶水（硅胶等） |
| **隔膜阀/柱塞阀** | 气压/机械 | 隔膜或柱塞定量挤出 | 无残留、适合腐蚀性/氰基丙烯酸酯 | 特殊流体 |
| **螺杆阀（容积式）** | 步进/伺服电机 | 螺旋转子在定子内旋转，密封腔体沿轴向推送胶体 | 对粘度不敏感、出胶量与转速线性、可处理含颗粒填料（锡膏、导热脂 30万–130万 cps） | 大胶量、高粘度：电源灌封、导热填充、银浆 |
| **压电喷射阀** | 压电陶瓷（~120V 驱动） | 压电堆瞬间形变驱动撞针高频撞击喷嘴，把液滴"射"出去 | 非接触、无 Z 轴动作、最高 1000–2000Hz、胶点可小至 0.2mm/0.5µl | 芯片封装、Underfill、摄像头模组、Micro LED |
| **气动喷射阀** | 高速电磁阀+气压 | 撞针与喷嘴快速开闭，胶束获得动能飞出 | 频率低于压电（150–280Hz）、可处理更高粘度（10万 cps+） | 中高粘度喷射场景 |

### 接触式 vs 非接触式

- **接触式**（针式/螺杆/柱塞）：针头降到基板（间隙 0.5–1mm），胶靠黏性力与针头分离成点；速度慢但适应性强
- **非接触式**（喷射）：喷嘴距基板 2–5mm，胶滴飞出；省去 Z 轴升降，速度快 10 倍以上，适合高度不一的脆弱元件

## 三、控制参数

### 核心工艺参数（以睿斯合 RSH-AI800 / 铭赛 KDC3004 / 武藏系列为典型）

| 参数 | 说明 | 典型范围/分辨率 |
|---|---|---|
| **点胶时间（脉冲时间）** | 开阀持续时间，微量点胶最核心的参数 | 0.001s–99.99s（最小 1ms 甚至 0.01ms 级） |
| **点胶压力（吐出气压）** | 推动胶体的气压 | 0.05–0.6 MPa（5–700 kPa），低粘度 20–80kPa、中粘度 80–200kPa |
| **真空回吸（负压）** | 关胶时回吸防拉丝滴漏 | 0 ~ -20 kPa；过大会吸入空气产生气泡 |
| **提前关胶/开胶延时** | 与运动配合的时序补偿 | 0.0x 秒级 |
| **点胶速度** | 画线时出胶与运动同步 | 螺杆阀=转速；喷射阀=频率 |
| **喷射频率** | 压电阀每秒打点次数 | 连续 1000Hz、瞬时 1500–2000Hz（武藏 SuperJet3 MAX 2000Hz） |
| **波形控制**（压电阀） | 撞针开启/关闭斜坡与行程 | Nordson PICO Wave Profile：斜坡开/关参数、行程控制 |
| **阀体温度** | 加热降粘（热熔胶/高粘胶） | 10–80℃，独立温控器 |
| **补偿参数** | α/δ 补偿、真空补偿 | 针对针筒液位下降的出胶量漂移 |
| **通道/配方** | 多组参数存储切换 | 100–400 通道 |

### 与运动配合的参数

- **点胶高度**：接触式 0.5–1mm；喷射式 2–5mm
- **拐角减速**：保证线宽一致（武藏 Synchro Speed 同步速度功能：转角自动调速保持涂布宽度）
- **回吸时间/拉丝处理**：与关胶延时配合

## 四、控制方式与通信接口

### 1. IO 触发（自动化最常用）

以武藏 SuperHiJet 规格书为典型（本项目同类方案）：

**输入信号**：涂布要求（点胶触发）、频道切换、点胶模式切换、频道预设、外部操作模式
**输出信号**：点胶完成、点胶中、错误、报警、繁忙、通电中、外部操作模式

- 电平：24V 有源 / 无源通断可选
- 工作方式：上位机（PLC/运动控制器）给"涂布要求"信号 → 控制器按当前通道参数出胶 → "点胶完成"信号反馈
- 高端机型支持"同步速度"：编码器/速度信号接入，出胶频率跟随运动速度

### 2. 串口 RS-232C（参数下发与远程控制）

- 武藏全系支持：USB + RS-232C "可收发所有参数及进行远程操作"（SuperHiJet、ScrewMaster3 等）
- 国产联网控制器（如 ML-6000X）：RS232 远程读写参数、存储多组工艺通道、读取压力日志
- 用途：配方下载、状态监控、计数读取、远程启停

### 3. 工业以太网（高端集成）

- **Nordson PICO Nexμs**：24V 导轨安装喷射控制器，支持 **PROFINET、EtherNet/IP**，NX 协议 over TCP/IP + Web 界面
- 趋势：点胶控制器正从"面板+IO"向"总线节点"演进，与 EtherCAT 运动控制系统融合

### 4. 控制器面板/脚踏（手动调试）

- 手动/定时/循环/教导模式，脚踏开关触发
- 用于试胶、找参数，自动化时切换到 IO/通信控制

## 六、对本项目的映射建议

当前 dispensing 系统的点胶控制器只有 `valve on/off` + 流量开关，对照真实设备建议扩展：

```csharp
// 命令
EquipmentCommand.SetDispenseParams(
    dispenseTimeMs,      // 点胶时间
    pressureKpa,         // 吐出气压
    vacuumKpa,           // 回吸负压
    frequencyHz,         // 喷射频率（喷射阀）
    temperatureC);       // 阀体温度
EquipmentCommand.DispenseTrigger(on);       // IO"涂布要求"
EquipmentCommand.SelectChannel(ch);         // 配方通道切换

// 快照增加
ValveSnapshot { Dispensing, PressureActual, VacuumActual, Temperature,
                ShotCount, Alarm, Busy }
```

虚拟点胶控制器（服务端）可模拟真实行为：

- 手动模式：写输出点 → 气压爬升 → 胶量输出；回吸负压影响断胶质量（拉丝/气泡）
- 自动模式：IO 由点胶流程接管，手动写入被拒（与现有 io.js 夹具/推杆的互锁逻辑同构）
- 喷射阀：频率上限、温度未达标禁止出胶、胶量 = f(时间, 气压, 粘度)
- 通信三通道齐备：IO 触发（与运动控制器联动）、RS-232 参数下发、状态回读（Busy/完成/报警）

这样真实点胶阀控制器接入时（无论武藏、诺信还是国产阀），平台/WPF/脚本同样无需改动。
