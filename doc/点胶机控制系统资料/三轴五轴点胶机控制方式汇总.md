# 主流三轴 / 五轴点胶机控制方式汇总

> 整理日期：2026-11-13。资料来源详见同目录 [资料来源.md](资料来源.md)，原始 PDF 见 `原始资料/` 子目录。
> 本文基于正运动、众为兴、恒控、研控、崧智、埃斯顿、灵猴、鸿达辉、大族等厂商公开文档整理，供本项目点胶平台控制系统建模参考。

---

## 一、总体架构：几乎所有点胶机都是"脱机运动控制器 + 示教盒"模式

```
示教盒（手持盒）══串口/RS485══ 运动控制器主板 ══脉冲/总线══ 伺服/步进驱动器
                                  ║                        ║
                              胶枪输出(电磁阀)           XYZ(A/C)轴
                                  ║
                          启动/暂停/急停/原点 输入
```

**主流形态**（恒控 HK-3D、研控 MSD400、福酷威 331、中科伺服 C100 等平台高度同质）：

- **主控板**：ARM + DSP/FPGA 方案，速度刷新 0.1–1ms，支持硬件三维直线/空间圆弧插补（非线段拟合）
- **示教盒**：4.3–5 寸 480×272 彩屏，与主板用**工业现场总线（RS485）**连接；负责编程、教导、参数设置、文件管理
- **脱机运行**：程序下载到控制器（SD 卡/Flash，128M–256M），加工时可脱离示教盒，通过拨码盘/DISPLAY 面板/IO 选择文件执行
- **文件来源**：手动示教 + DXF/PLT/CVS 导入（PCB 行业可直接导入元件坐标生成点胶路径）+ U 盘交互

**IO 配置**（三轴平台典型值）：8 路专用输入（XYZ 原点、启动/暂停、复位/急停）、4–8 路胶枪输出（直接驱动电磁阀 0.5–2A）、8–16 路通用 IO。点胶时间控制精度 1ms。

**每条运动指令可独立携带的工艺参数**：开胶延时、关胶延时、提前关胶、退枪高度、点胶速度、空移速度、拐角优先级——这是点胶控制区别于普通 CNC 的核心特征（出胶时序与轨迹点绑定）。

## 二、三轴点胶机控制方式

### 运动控制

- 3 轴 XYZ，脉冲输出（脉冲+方向），最高脉冲频率 0.2–4 MHz（恒控 F00 达 4MHz）
- **真三维空间圆弧插补**（硬件实现）、抛物线拐角过渡、回原点三轴同时原点捕获
- 图形元素：点、直线、多段线、空间圆弧、圆、椭圆、跑道、矩形、螺旋线、环形/矩形涂布、样条曲线
- 扩展形态：3 轴 + 双 Y（双工位交替）、3 轴 + R 轴（旋转，可与 XY 路径切线跟随）

### 代表控制器

| 控制器 | 轴数 | 方案 | 特点 |
|---|---|---|---|
| 恒控 HK-3D-A101/F00 | 3（可扩 3+2Y+R） | ARM+DSP+FPGA | 1MHz 直线插补、DXF 转换、4 种拉丝工艺、1000 个文件×4000 点 |
| 研控 MSD400 | 4（3+双Y/R） | ARM+FPGA | 128M 存 500 文件×4000 指令、5 寸触摸屏、速度曲线实时显示 |
| 正运动 ZMC303 | 3（可扩 10） | 独立式脉冲控制器 | ZBasic 多任务编程、电子凸轮/齿轮、10MHz 脉冲 |
| 福酷威 331 / 中科 C100 | 3 | 手持盒平台 | 4 胶枪通道、1ms 点胶精度、脱机卡 2G SD |

### 上位机接口（三轴脱机系统）

- 示教盒串口（参数/程序下载）
- U 盘/SD 卡文件交换
- 对外：启动/停止/复位 IO、完成信号输出、少量 RS485
- **特点：不开放实时控制协议**，自动化集成靠 IO 联动，路径必须预先示教/导入

## 三、五轴点胶机控制方式

### 为什么需要五轴

三轴胶枪始终垂直向下，只能做平面；四轴加单旋转只能平面旋转。五轴（XYZ + A 绕 X + C 绕 Z）让点胶头/工件空间自由倾斜旋转，**使胶枪始终垂直于曲面法向**，解决手机中框四边密封、TWS 腔体弧面、摄像头模组环形密封等 3D 场景。

### 核心控制技术

1. **RTCP（旋转刀具中心点）**——真五轴的标志
   - 编程只关心胶枪尖与工件的插补运动，旋转轴补偿由控制器实时解算
   - 保持针尖始终走在编程轨迹上，同时优化胶枪姿态
   - 众为兴 DJ1600V4 的 RTCP 拟合标定算法：通过测量模块数据处理，精确计算旋转轴轴线方向和偏移
2. **小线段前瞻 + 匀速过弯**：提高轨道速度，保证等距出胶
3. **胶量-速度非线性补偿**：斜坡/曲面区域动态调整移动速度与出胶量，保证胶路宽度一致
4. **五轴联动形式**（五种搭建形式）：双旋转台、双摆头、一摆一转等，按产品/环境选择

### 代表方案

| 方案 | 构成 | 特点 |
|---|---|---|
| 众为兴 DJ1600V4 | TV5600 手持盒 + AMC1600P 脱机卡（脉冲 5-6 轴） | RTCP、兼容四轴、IEC61131-3 PLCOpen 指令、G 代码导入 |
| 正运动 VPLC516E 五轴方案 | 视觉运动控制一体机 + EtherCAT | 单/双 5 轴 RTCP、视觉定位纠偏、胶路检测、三种出胶工艺 |
| 崧智 AOS | PC-based 软件 + 总线/脉冲控制 | 700+ 构型库、3D 模型导入示教、自动测高、激光测高 |
| 埃斯顿五轴方案 | 运动控制器 + 伺服 | 2000mm/s、精度 0.02mm、数字孪生轨迹规划 |
| 鸿达辉 HDH-5000 / 大族 HDM-GW5010L | 直线电机 + DDR 直驱在线式 | 视觉引导、飞拍、±3μm 重复精度 |

### 五轴系统的额外配置

- **视觉系统**：2D/3D 相机 + 激光位移传感器；视觉定位纠偏、来料扫码、胶路有无检测
- **自动标定**：双旋转台水平校准、偏移校准、针头 XYZ 三方向自动对针、激光测高
- **上位机通信**：与 PLC/机械手串口或网口通讯（上下料联动）、产线 MES 对接

## 四、控制方式分类对比

| 维度 | 三轴桌面/平台机 | 五轴精密机 |
|---|---|---|
| 控制硬件 | ARM 脱机板 + 示教盒 | 脱机卡/总线控制器 + 示教盒或 PC |
| 插补 | 3 轴直线 + 空间圆弧 | 5 轴联动 RTCP、样条 |
| 编程 | 手持示教、DXF/PLT 导入 | + 3D 模型导入、相机示教、离线 CAM |
| 出胶控制 | 胶枪 IO + 每条指令独立时序参数 | + 阀控制器联动（压电/螺杆/喷射）、速度-胶量补偿 |
| 自动化接口 | 启动/停止 IO、U 盘 | 总线（EtherCAT/PROFINET）、PLC 联机、视觉 |
| 精度 | ±0.02–0.05mm | ±0.01–0.08mm（直线电机+DDR 可达 ±3μm 重复） |

## 五、对本项目的映射建议

当前 dispensing 项目是"Node 服务端模拟控制器 + Web 3D + WPF/脚本上位机"，对标真实点胶机的差距与建议：

1. **指令模型**：现有点胶路径是 `{points, feed, valveOn}` 折线。真实点胶机是"运动指令 + 工艺参数"绑定结构，建议扩展为：
   ```json
   { "kind": "move", "points": [[x,y,z]], "feed": 80,
     "valve": { "openDelayMs": 5, "closeDelayMs": 10, "earlyCloseMs": 3,
                "retractMm": 2, "pressureKpa": 120 } }
   ```
2. **空间圆弧插补**：现只有 Line3D。三轴机都有硬件空间圆弧，建议加 `Arc3DPath`（圆心+法向量），这是后续五轴的基础
3. **出胶与运动同步**：参考"提前关胶/拐角减速"机制——模拟器在减速段自动提前关阀，胶路末端不堆胶
4. **RTCP 预留**：`MachineConfig` 已支持 gantry/cantilever/movingTable 构型，若未来做五轴，在轴层增加 A/C 旋转轴定义 + 坐标系变换模块即可，平台/WPF 接口不需要变
5. **示教文件格式**：真实行业标准是"加工文件 + 工艺参数 + DXF 导入"，现有 `upload` 协议已接近，可补充 DXF 解析（dispensing/host 已有 CAD 导入能力可复用）
