# 市面主流激光器控制方式汇总

> 整理日期：2026-11-13。资料来源详见同目录 [资料来源.md](资料来源.md)，原始 PDF 见 `原始资料/` 子目录。
> 本文基于锐科（Raycus）、IPG、金橙子（JCZ）、正运动、柏楚（FSCUT）等厂商公开说明书与控制卡文档整理。

---

## 一、两大应用范式

| 范式 | 典型场景 | 控制核心 | 常见品牌/方案 |
|---|---|---|---|
| **振镜打标** | 激光打标、雕刻、微加工 | 打标控制卡同时驱动振镜（XY2-100 协议）和激光器 | 金橙子（JCZ/EZCAD）、大族、华工、IPG 打标模块 |
| **运动平台 + 出光** | 切割、焊接、熔覆、点焊 | 运动控制器管轴，激光控制卡/协议管出光和能量 | 锐科、IPG、创鑫、杰普特的激光器 + 柏楚 FSCUT、正运动、固高的控制系统 |

本项目（XY+Z 三轴平台 + 激光 + 自动上下料）属于第二种形态：平台走插补轨迹，激光按工艺参数出光。

---

## 二、主要控制参数

### 能量参数（下发）

| 参数 | 说明 | 典型范围（举例） |
|---|---|---|
| **功率** | 瓦数（W）或百分比 0~100% | 锐科 CW 系列 10~100%；DB25 并口用 8bit（0–255）编码 |
| **重复频率** | 脉冲模式下每秒出光次数 | 锐科脉冲系列 10–50 kHz；打标 TTL 频率信号 1 kHz–2 MHz；QCW 0–5 kHz |
| **脉冲宽度** | 单脉冲持续时间 | QCW 系列 0.05–50 ms；脉冲光纤 90–130 ns |
| **占空比** | 调制模式下脉宽占周期比例 | 0–100% |
| **泵浦电流** | 半导体激光器直接给定电流 | 模拟电压 0–10V 或 0–5V 映射 0–100% 电流 |

### 状态参数（回读）

- 激光器温度、实际输出功率、光闸状态、固件版本
- 报警码：锐科用 `TE1`–`TE10` 上报 Error 1–10；互锁状态、外控/内控模式指示

### 辅助控制

- **红光指示（Red Dot）**：定位用，独立开关
- **预出光 / 光闸（MO / Gate）**：先开泵浦预热，再允许出光
- **使能 / 互锁（Enable / Interlock）**：安全回路，如 ITL_A/ITL_B 短接、LAS_C 高电平才允许出光
- **吹气 / 辅助气体**：切割场景，通常归 CNC 控制器管

## 三、控制协议（从底层到上层）

### 1. 硬件信号层（DB25 / 接线端子）

打标机和小功率设备最常用。以锐科 RFL-P120MX 的 DB25 控制口为例：

| 引脚 | 信号 | 说明 |
|---|---|---|
| 1–8 | D0–D7 | 8bit 功率给定（0–255 对应 0–100% 泵浦电流） |
| 18 | MO | 预出光信号，高电平开 |
| 19 | 出光 GATE | 高电平出光 |
| 20 | 频率 | TTL 电平，1 kHz–2000 kHz |
| 22 | 红光 | 高电平开红光 |
| 11/12/16/21 | 报警输出 | 光耦隔离 |
| 10/13–15/24/25 | GND | 信号地 |

其他常见信号：

- **0–10V 模拟量**调功率：IPG YLR 用 Han 7D 接口，0V=0%、10V=100% 泵浦电流，静态精度 ±2%，响应 ≤50µs
- **24V PWM 调制**：占空比 1–99%
- **Enable / Alarm / 互锁**：24V 或 5V 电平

**激光控制卡的价值**：上位机不直接攒这些 TTL 信号，而是由控制卡（金橙子 LMCV4、PDU1000 等）把 PC 指令转换成满足时序要求的硬件信号。

### 2. 串口 RS-232（中功率标准配置）

- 参数统一为 **9600 / 8 / N / 1**
- 锐科老协议：十六进制帧

  ```
  FE FE FE 68 | 地址(2B) | 命令字(1B) | 备用(1B) | 数据长度(2B) | 数据(N) | CRC16(2B) | 0x55
  ```

  命令字如 `0x31` 读参数、`0x30` 问询状态。

- 锐科新协议（简化 ASCII 命令，以 `\r` 结束）：

  | 命令 | 示例 | 含义 |
  |---|---|---|
  | `1B4F0D` | 发送后回应 `TS 0D` | 开光闸 |
  | `1B530D` | 回应 `TS 0D` | 关光闸 |
  | `1B4350XX0D` | `1B4350320D` | 连续模式，XX=功率百分比（十六进制，0–100） |
  | `1B46XXXX44##&&0D` | `1B461388443C500D` | 调制模式：频率 5000Hz、占空比 60%、功率 80% |
  | 错误回应 | `TE1 0D`–`TE10 0D` | 上报 Error 1–10 |

- 用途：设置工作模式/参数/开关光闸。注意 RS-232 模式下出光仍需外部调制信号配合。

### 3. 以太网（大功率 / 远程）

- 锐科 RFL-A 系列：默认 IP `192.168.0.10`，**UDP 端口 8098**，单包发送，命令集与串口相同；修改 IP 需默认密码 `1122334455667788`
- IPG YLR：Industrial Ethernet（RJ45）用于监控与控制；另有模拟量 + 24V Laser ON/OFF（最大 5 kHz 调制）+ Han 64D 机器人硬线直控

### 4. 现场总线 EtherCAT（高端集成：运动 + 激光一体）

- **IPG YLR/YLPP Fieldbus 接口**：周期报文中直接映像 `SET_POWER`（Uint16，单位 %，scale 10）等参数，主站是 PLC/运动控制器
- **金橙子 PDU1000-EtherCAT 卡**：专为总线激光焊接，百兆网口 + XY2-100 振镜 + 分光卡接口
- **正运动 ZMC408SCAN**：8 轴 EtherCAT 运动 + 振镜 + 激光一体；激光电源接口原生支持 IPG YLR/YLS，0–10V/PWM 输出与运动速度同步（功率随速调节）
- **柏楚 FSCUT**：BMC228A 卡跑 EtherCAT 主站协议栈，同时管运动、激光、切割气体——国产激光切割的主流形态

### 5. 控制卡 + SDK（打标领域标准做法）

金橙子（JCZ）LMCV4 / LMCPCIE / DLC 卡 + EZCAD2/3 软件，第三方二次开发通过 **MarkEzd.dll**：

```csharp
lmc1_Initial(tzwPath, bTestMode, hOwenWnd);   // 初始化控制卡
lmc1_Mark(0);                                  // 开始标刻
lmc1_StopMark();                               // 停止
lmc1_AxisMoveTo(axis, GoalPos);                // 扩展轴运动
lmc1_GetCurCoor(ref x, ref y);                 // 读当前坐标
lmc1_SetParam(...);                            // 功率/频率/速度等参数
```

特点：上位机不碰激光器硬件，只把图形对象 + 工艺参数交给控制卡，由它合成"振镜轨迹 + 出光时序"。

## 四、上位机调用路径（工程实践）

```
路径A（打标机）:   上位机 → MarkEzd.dll → 打标卡 → DB25 → 激光器
路径B（切割/焊接）: 上位机 → 运动控制器(EtherCAT 主站) → 伺服 + 激光控制卡 → 激光器
路径C（直接协议）:  上位机 → SerialPort / UdpClient → 锐科/IPG 命令协议
路径D（PLC 集成）:  PLC(EtherCAT 主站) → IPG Fieldbus → 周期写 SET_POWER / GATE
```

- **路径 C 最简单**：打开串口发 ASCII 帧，或 UDP 发命令包，适合"平台运动 + 简单出光"的设备
- 工业上很少让激光器裸连上位机，中间通常隔一层卡或网关，用于安全互锁和高速出光时序

## 五、对本项目的映射建议

当前项目的 `ILaserControlPort` 只有 `laser on/off`，对照真实设备建议扩展为参数化命令：

```csharp
// 命令
EquipmentCommand.SetLaserParams(powerPercent, frequencyHz, pulseWidthNs, dutyCycle);
EquipmentCommand.LaserGate(on);          // 对应 Gate / MO
EquipmentCommand.SetRedPointer(on);      // 红光

// 快照增加
LaserSnapshot { PowerPercent, FrequencyHz, PulseWidth, DutyCycle,
                GateOn, RedPointerOn, Temperature, AlarmCode, InterlockOk }
```

Node 端 `/ws/laser` 虚拟激光控制卡可模拟真实行为：

- 互锁未闭合时拒绝出光
- 频率/占空比超出范围报错（类似锐科 `TE` 错误码）
- 回读功率、温度、报警状态

这样真实 `RealLaserControlPort` 落地时（无论走串口、UDP 还是 EtherCAT 网关），平台 / WPF / 脚本一行都不用改——这正是硬件通道拆分的价值。
